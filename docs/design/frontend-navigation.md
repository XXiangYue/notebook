# 前端导航与知识列表设计

原始设计日期：2026-07-09。整理日期：2026-10-23。

**状态：部分实现。** 本页保留重构意图，并按现有代码区分已实现内容与后续工作。

## 背景

原导航入口较多，知识列表的分类卡片与行间距占用较多屏幕空间。
`public/knowledge-list.js` 还承担部分表单与列表事件处理，需要逐步迁移至 React，避免两套交互逻辑并存。

## 已实现

- 顶部导航为“知识库、搜索、设置”，另有“新增知识”按钮。
- `/` 重定向到 `/knowledge`，分类管理位于设置页。
- Markdown 预览切换已由 React state 管理。
- `OrganizeJobWatcher` 提供整理任务轮询，详情页保留启动失败提示。
- 已新增 `KnowledgeListPanel` 紧凑列表组件。

## 后续工作

- 将 `KnowledgeListPanel` 接入知识库页面，替换现有列表组件。
- 使用状态标签和分类筛选替代大块分类卡片，降低列表行高。
- 将待处理、最近删除视图整合到知识库，再处理旧路由迁移。
- 迁移 `public/knowledge-list.js` 剩余事件逻辑后，移除脚本及 `layout.tsx` 中的注入。

目前旧列表、独立的待处理和最近删除页面、原生脚本仍在使用，整理仓库时应保留。

## 验证方式

完成后运行 `make check`，并手动验证“新建草稿 → 整理 → 确认 → 分类筛选 → 删除 → 恢复”的流程。
同时检查错误提示、批量操作失败后的列表状态，以及桌面端重新启动后的表现。
